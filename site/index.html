Your agent runs next to the code. You stay wherever you are.

1

Type claude locally

A built-in SSH proxy logs you in (no password or key prompts) and starts Claude Code inside the mounted project directory. Sub-folders map to remote sub-folders.

2

Watch every edit

The directory is mounted as a local drive or folder. Open it in VS Code, Finder or Explorer and review the agent's changes as it works; every open is checked against the server.

3

Close the lid

Code, builds and the agent live on the server. Set the command to tmux new -As claude claude and the session survives disconnects.

Works the same for codex, aider, gemini or any CLI — one custom command each.

Everything you need, nothing on the server

Plain SSH/SFTP

Nothing to install on the server. WinFsp on Windows, FUSE-T on macOS (no kernel extension).

Fast local cache

Files download once, then open instantly. Each open re-validates against the server.

Write-back upload

Saves land locally and upload in the background — even after a crash or power loss.

Password-free commands

Local commands reuse FileLoad's authenticated connection through a loopback proxy.

Resilient

Auto-reconnect, keepalive, one-click re-mount from history, tray/menu-bar mode.

Auto-update

New versions download, install and relaunch with one click.

Up and running in a minute

  1. Install — Windows installer (includes WinFsp) or macOS dmg.
  2. Connect & mount — host, user, key or password; pick a remote folder.
  3. Add claude — on the Commands page, then open a new terminal and type it.

FAQ

Do I need to install anything on the server?

Only an SSH server with SFTP (the OpenSSH default), plus the CLI you want to run there, such as Claude Code.

Is the local proxy exposed to my network?

No. It listens on 127.0.0.1 only, and only while a mount is active.

macOS says the app can't be opened.

The app isn't notarized yet. Right-click FileLoad in Applications › Open, once.

What language is the app in?

The UI is currently Simplified Chinese; English is on the roadmap.

Is it free?

Yes. FileLoad is MIT licensed. The macOS build bundles FUSE-T, which is free for non-commercial use.
